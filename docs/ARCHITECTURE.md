# Neural Clash: Architecture

Record expensive-to-reverse decisions as ADRs in `docs/adr/NNNN-title.md`.

## 1. Stack
Next.js 16 (static export, `basePath` `/neural-clash`), React 19, TypeScript strict, PixiJS 8, CodeMirror 6 (`@codemirror/lang-python` + `@codemirror/lang-cpp`), Tailwind 4, IndexedDB saves (versioned, migrations, export/import), the Query Clash service worker (keep the worker-fragment fix), Vitest, native verification (python3 + numpy, g++), and Playwright.

## 2. Python runtime (Pyodide)
- **Pyodide** with numpy, lazily loaded only on Lab, Training ("Run my code"), workshop and Python-judge screens, in a dedicated worker with a progress UI. Check the current Pyodide version and its numpy package on npm/CDN when implementing, and record an ADR covering size, load time, offline caching (service worker caches the Pyodide assets after first use) and the iPhone policy.
- **Execution model:** a fresh interpreter state per submission (or `pyodide.runPython` in an isolated namespace with module reloading). Timeouts via `worker.terminate()` and a respawn. stdout/stderr capture. Memory guard (array-size limits in the harness).
- **The player's framework (`latent`)** is stored as files in the save file and mounted into Pyodide's virtual FS as a package, so later modules import earlier ones. A "use reference" toggle mounts the reference package instead (marked assisted).
- **Test harness:** an in-repo Python mini framework (`nc_test`) with assertions, `allclose` tolerances, a **finite-difference gradient checker** (central differences, relative error threshold, float64), shape checks, seeds, and structured JSON results. Hidden tests are shipped as data and executed in the worker; they are visible only in the debrief.

## 3. C++ judge
Port Algo Clash's `lib/judge/` (clang→WASM via `@yowasp/clang`, which ships libc++ for wasm32-wasip1; LeetCode harness; verdicts; friendly clang errors) from `/home/user/algo-clash` if it exists. Otherwise do its spike (Algo Clash ARCH §2) and write an ADR here. Problem packages share Algo Clash's format so problems can be ported.

## 4. Native verification (`npm run content:verify`)
- **Python:** every Lab module reference passes its hidden tests and gradient checks under native python3 + numpy (pinned versions in `requirements-dev.txt`; CI installs them). Known-wrong implementations (`wrong/*.py`: a missing transpose in backward, a non-stable softmax, a wrong Adam bias correction…) must fail.
- **C++:** the same as Algo Clash (reference vs brute stress tests; wrong solutions rejected).
- **Cards:** derive-it, shape, metric and curve cards are generated by solver code (`lib/solvers/` in TS, cross-checked against Python reference functions on fixed cases).
- **Workshops:** golden-set metrics for reference pipelines meet their documented targets. Planted biases in the judge dataset are detectable by the reference analysis at the documented significance.
- **Comprehension and pair codebases:** every seeded bug has a failing test on the buggy version and a passing one on the fixed version. Every scripted assistant suggestion is labelled correct or wrong, and wrong ones are proven wrong by a test.

## 5. Training Grounds engine
- A **fast TS trainer** (`lib/train/`): MLP, a small CNN and a tiny transformer forward/backward in Float32Array with WebGL/WebGPU optional later (ADR). It runs in a worker with live metrics.
- **Equivalence tests:** on fixed seeds, the TS trainer's forward outputs, gradients and N optimisation steps match the Python reference within tolerance.
- The "Run my code" path trains with the player's Pyodide implementation (slower, smaller budgets).
- **Datasets** are generated in-repo by seeded scripts (`scripts/data/`) and committed as compact binaries or JSON: toys, Glyphs (16×16), Creature Stats (tabular, with documented leakage/confounder/imbalance), Lore Corpus (original text), and the Lumen Labs Handbook + golden Q&A for RAG.

## 6. LLM-system simulators (`lib/llmsim/`)
- **Scripted fake LLM (test double):** scenario scripts map (conversation state, tool results) → next message or tool call. It's deterministic and versioned, and always labelled "simulated" in the UI.
- **Judge dataset generator:** documented generative process with planted length and position biases and known human labels.
- **Ops Observatory simulator:** request generator (types, token distributions), model tiers with illustrative latency/cost/quality curves, caches (exact, semantic with a similarity threshold → hit rate and false-hit rate), router, fallbacks, rate limits, failures. Tick-based like Blueprint Clash's simulator (port shared code if present). Validation tests: cache hit-rate maths, latency percentile composition, cost accounting.
- **Attack suite** for the Safety Sanctum: deterministic injection strings embedded in docs and tool outputs. A scenario passes when no unsafe tool call happens under the scripted model's documented "naive" policy once the player's defences are in place.

## 7. Codebase viewer (Comprehension and Pair)
A multi-file read/write editor with a file tree, search, and **jump-to-definition** from a symbol index built at content build time (a Python AST via the native script; C++ via clang AST JSON natively). Runs tests in Pyodide or the C++ judge. The Pair Pavilion assistant panel is driven by `lib/llmsim/` scripts with intent matching (keyword/embedding-lite classifier, tested).

## 8. Game runtime and routes
`game/` holds the Pixi scenes. `lib/battle/`, `lib/srs/`, `lib/save/`, `lib/audio/` and `lib/dialogue/` are ported from Algo Clash where present.

Routes: `/` · `/play` · `/lab/[module]` · `/train` · `/dojo/[id]` (C++/Python problems) · `/reef` · `/courthouse` · `/arcology` · `/sanctum` · `/observatory` · `/catacombs/[id]` · `/pair/[id]` · `/spire` (AI design) · `/product` · `/library` · `/journal` · `/trainer` · `/settings` · `/dev/sprites` · `/dev/judge` · `/dev/pyodide`.

## 9. Budgets
First-load JS ≤ 300 KB gzip (Pyodide, clang, trainers and simulators are lazy and in workers), a 60 fps overworld on an iPhone 14, live training charts at ≥ 20 updates/s on desktop, no console errors, and no horizontal overflow at 390 px.
