# Neural Clash

Raise a neural creature, literally. Your companion is a model **you implement from scratch** in Python/numpy, right in the browser, and train. Battles test whether it, and you, generalise.

- **Forge Your Framework:** build a mini deep-learning library (autograd → MLP → optimisers → CNN → attention → transformer → BPE tokenizer → sampling → tiny LM), with gradient-checked hidden tests. The game then runs *your* code.
- **Training Grounds:** tune and train on original datasets, then face Overfit, Leakage, Drift and the Imbalance Swarm on hidden test sets.
- **Building with LLMs:** RAG with real retrieval metrics, LLM-as-judge calibration and bias detection, agent loops with guardrails, prompt-injection defences, and cost/latency budgets in an LLMOps simulator.
- **Interview tracks:** C++ LeetCode medium/hard on a real in-browser compiler, AI-flavoured implement-from-scratch problems, code-comprehension rounds, AI-assisted coding rounds (with a clearly simulated assistant), and AI system design and product-sense mocks.
